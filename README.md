# CyberShield AI Security Assistant

## Overview

CyberShield is an AI-powered desktop security assistant designed to protect users from phishing attacks, malicious websites, scam content, and suspicious links in real time.

The system monitors screen content, extracts text using OCR, analyzes URLs and webpage content, and classifies detected threats into:

* Safe
* Medium Risk
* Dangerous

CyberShield provides instant alerts and security recommendations to help users avoid online threats.

---

## Features

### Real-Time Screen Analysis

* Scan the entire screen
* Scan a selected screen region
* Analyze screen recordings

### OCR-Based Content Detection

* Extract text from screen content
* Detect suspicious keywords and scam messages

### URL Security Analysis

* Identify phishing links
* Detect malicious websites
* Flag suspicious domains

### Threat Classification

* Safe
* Medium Risk
* Dangerous

### Desktop Automation

* Shortcut key activation
* Fast threat assessment
* User-friendly interface
